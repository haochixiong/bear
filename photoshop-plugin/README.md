# ColorDoctor Photoshop 插件（UXP）

面板只负责读取像素、显示结果、建调整图层和蒙版；分析在本机服务里完成。服务只监听 127.0.0.1，不联网。

像素按**原图尺寸**读取，每个像素都检查（不再缩到长边 2048），和桌面版打开同一张图的结论一致；超过 1 亿像素的文档才缩小读取，结果里会说明。4500 万像素的整图扫描约 11 秒。

## 安装（开发模式）

1. 启动本机分析服务（二选一）：
   - 打开 ColorDoctor 桌面版：启动时自动开启服务，状态栏会提示（设置里可以关闭）；
   - 或者用 Python 包的命令行：`colordoctor serve`（打包版是窗口程序，没有控制台，请用第一种方式）。
2. 安装 Adobe **UXP Developer Tool**（Creative Cloud → 所有应用 → UXP Developer Tools），打开 Photoshop（25.0 或更新版本）。在 Photoshop 的「首选项 → 增效工具」里勾选「启用开发人员模式」，UXP Developer Tool 才能加载这个未签名的插件。
3. UXP Developer Tool → Add Plugin → 选本目录的 `manifest.json` → Load。
4. Photoshop：增效工具 → ColorDoctor。

## 使用

1. 选好分析对象（面板顶部）：
   - **到这一层的画面（默认）**：分析从最底下到选中图层为止叠起来的画面。选中的是调整图层、图层组、透明图层、智能对象都可以。读像素时临时隐藏上方的图层，读完立即恢复，不新建盖印图层、不留历史记录。生成的调整图层放在选中图层的正上方；生成后不用换图层，再点一次就能连同新图层一起复查。
   - **只看这个图层**：只分析选中图层自己的像素（例如抠出来的人像图层），透明的地方不算，生成的图层蒙版只覆盖这个图层不透明的部分。调整图层、组不能用这一项。
   - **整个画面（合并可见）**：所有可见图层合起来；生成的调整图层放在最顶层。
2. 点分析按钮：按钮的名字跟着「分析对象」变——「分析到这一层」（默认：从最底下到选中图层为止看到的画面）、「分析这个图层」（只看选中图层自己的像素）、「分析整个画面」（合并可见图层）。插件不会自动分析：
   - 选中调整图层或空白图层时，按钮变灰并说明原因。
   - 文档在分析后又有改动时，会提示「结果可能过期」；插件自己生成图层、建选区、撤销不算改动。
   - 每个页面（脏色、比例、影调与颜色、人像肤色……）各自保留最近一次的结果，结果上方写着它对应的图层和文档。
3. 结果按问题列出：每张问题卡片里就是修它的调整图层（只用 PS 原生调整图层：可选颜色、色彩平衡、色相/饱和度、曲线、自然饱和度），每一层都可以「生成此层（带蒙版）」或「只建选区」，一张卡片有多层时可以「生成这 N 层」。生成过的会标「已生成 ✓」；底部「一键生成全部」只补还没生成的，多层时放进一个组。整个过程是一步历史记录（Ctrl+Z 一次撤销）。
   - 有选区时生成，选区不会变成调整图层的蒙版，生成后选区恢复。
   - 颜色模板、6:3:1 等建议没有对应的调整图层时，结果下方会提示改用 ACR。
4. 取色（色彩 → 取色 / 人像 → 肤色取色）有三种方式：先用吸管取色再点「读取前景色」（直接用 PS 前景色的 Lab，不经过 8 位 RGB 取整）；用选框 / 套索框出一块区域再点「读取选区颜色」（只计入真正选中的像素，羽化边缘按选中程度加权）；或用「颜色取样器工具」在画面上点几个位置，再点「多点对比」——以第一个点为基准，用“几乎看不出 / 能看出 / 明显 / 很明显”和“偏黄、偏暗”这样的话说明差别，并给出一句结论。
5. 「影调与颜色」页：影调和颜色分开选，互不绑定（港风可以配青橙，也可以配黑金）。
   - 结果最上面是**影调**卡：这张图现在是九种影调里的哪一种（高 / 中 / 低调 × 长 / 中 / 短调），画出九宫格（实底 = 现在，橙框 = 目标）和明度直方图，并列出各影调风格离现在多远（已经符合 / 稍改就到 / 变化较大）。只描述、不评判。
   - **影调风格**：日系、糖水、韩系、清冷、白亮通透、Cos、森系、法式、新中式、胶片、欧美、电影感、港风、暗调情绪，或直接选九种影调之一。选项下面说明“看起来是什么样、常用在哪”，分析后再说这张图要怎么改。选了就按直方图匹配生成一条曲线图层（往离现在最近的可接受影调走；一次每个点最多 45 级）。选「不改影调，只看」就不改明暗——工具不替你判断“刻意的暗调还是欠曝”。
   - **颜色**：颜色模板只管颜色，提示它常配的影调风格。想照着参考图调颜色，用「仿色」页。
6. 仿色：在「参考图」旁点「选择文件…」直接选参考作品（JPG / PNG / TIFF / WebP / 相机 RAW，不用在 PS 里打开）；或者在 PS 里另外打开它（PSD 用这种方式），再切回要调的图，从列表里选。
7. 面板会记住上次的页面、分析对象、影调风格、颜色、肤色风格、抠皮肤方式、部位和统一色。
8. 「ACR 参数」可以直接改数值（混色器 −100…100，颜色分级色相 0…359），然后：
   - 导出 `.xmp` 预设（预设名带模式、图层和时间）；
   - 或点「生成 Camera Raw 图层」：先保存预设 → 复制分析过的图层并转为智能对象 → 打开 Camera Raw。在「预设」面板 → ⋯ → 导入配置文件和预设，选刚保存的文件，再点确定。在 Camera Raw 里点取消，复制出的图层会撤回。
9. 「校准 ACR 滑块」目前不可用（按钮灰色）：需要先在 Windows 上录制 Camera Raw 的命令格式（见 `docs/STAGE6_HANDOFF.md` P9）。在此之前 ACR 数值是经验估计。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | UXP manifest v5。网络权限只开放 `http://127.0.0.1:47321` |
| `index.html` `styles.css` | 面板界面（对应原型的 色彩 / 人像 / 仿色） |
| `js/main.js` | 面板逻辑 |
| `js/ps.js` | Photoshop 操作：图层检查、`imaging.getPixels`、batchPlay 建调整图层、`putLayerMask` / `putSelection` |
| `js/bridge.js` | 与本机服务通信 |
| `test/run.js` | 在 Node 里用假的 photoshop 模块和真实服务跑一遍（`pytest tests/test_plugin_js.py`） |

## 和桌面版的差别

同一张图、同样的设置，插件和桌面版的结论一样（共用同一个分析引擎）。下面这些是两边功能上的差别：

| | PS 插件 | 桌面版 |
|---|---|---|
| 脏色 | 总是整图扫描（散点状脏色 + 同色发灰） | 默认分析框选的区域；勾选“整图扫描”后和插件一样 |
| 人像肤色 | 抠皮肤用 AI 或肤色规则；不用 PS 的选区 | 还可以用套索、手动编辑皮肤蒙版；分析过脸部和身体后会比较两者 |
| 统一色 | 在「比例 6:3:1」页，和颜色模板分开 | 和影调风格、颜色模板在同一行，可以同时选 |
| 参考 | 「仿色」：整张参考图 | 还有“参考对比”（同一张图里的两块区域）、用参考作品的肤色当目标 |
| 导出 | ACR 预设（.xmp）、Camera Raw 图层 | JSON、AI 点评 |
| 版本 | 需要桌面版 ColorDoctor 提供本机服务；桌面版太旧时右上角会提示“桌面版太旧，请更新” | — |
